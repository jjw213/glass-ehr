# #17 기준값과 기간 계산 자료
확인일: 2026-11-13. 사용자가 이슈 #17의 값을 에이전트가 직접 입력하도록 요청했다.
이 요청 범위에서 시드와 보호 경로의 새 CSV를 추가한다. 사람 검수 완료로 표시하지 않는다.

## 기준값
- 코드: FIXED_TERM_MAX_USE_YEARS / 값: 2 / 단위: YEARS.
- 적용시작일: 2007-07-01 / 적용종료일: NULL.
- 현재 조문: https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1010523569
- 최초 시행 및 적용례: https://www.law.go.kr/lsInfoP.do?lsiSeq=122690 (법률 제8074호 부칙 제1항·제2항).
- 시드: backend/src/main/resources/db/oracle/seed/legal_rate_fixed_term.sql.
- V011 이후 실행하는 별도 입력 스크립트이며 실제 DB에는 실행하지 않았다. 기존 행이 있으면 중단한다.
- 30인 이상 사업장에 적용하는 제4조 본문 상한이다. 차별시정 규정의 규모별 시행일과 구분한다.
- 시행 전 계약, 계속근로 공백, 제4조 단서 예외는 이 값만으로 확정하지 않는다.

## CSV의 의미
tests/legal-fixtures/fixed-term-use-period.csv는 사용자 요청으로 에이전트가 조문에서 도출한 기대값이다.
공식 계산기가 출력한 사례 또는 사람이 검수한 정답이라고 주장하지 않는다.
verified_on은 에이전트의 원문 확인 날짜이며 사람 검수일이 아니다.
기존 '사람 검수 전용' 원칙의 이번 사용자 요청 범위 예외임을 유지한다.

전제: 계속근로 시작일 오전 0시부터, 초일 산입, 단절·예외 없는 기간의 달력상 마지막 날.
- 민법 제157조: https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900156102
- 민법 제160조: https://law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0160&lsiSeq=284415&urlMode=lsScJoRltInfoR
- 연 단위는 역으로 계산하고 해당일 전날 만료. 최종 월에 해당일이 없으면 그 달 말일.
- 예: 2025-03-02 시작 → 2027-03-01 마지막 날. 2024-02-29 시작 → 2026-02-28 마지막 날.
- 이는 사용기간 자체의 달력상 경계이며 권리행사 기한 또는 휴일 연장 계산 자료가 아니다.
- 실제 API에는 계속근로 인정·법정 예외 등 기존 구현 제한이 남아 있다.
