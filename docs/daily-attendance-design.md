# 일별 출근·결근 판정 (#114)

## 1. 목적
일별 근로시간 집계(#29 `attendance_daily_summary`)와 승인된 휴가(`ApprovedLeaveProvider`)로 날마다 출근·결근·휴가·휴일을 판정한다.
연차 발생(#33)의 출근율(근로기준법 제60조 제1항·제2항: 소정근로일 중 출근한 비율) 계산이 이 결과를 쓴다.

## 2. 구조
- `DailyAttendanceService.judge(empId, from, to)` → `Period`(소정근로일 수, 결근일 수, 날짜별 `Day(date, status, issues)`). 저장하지 않는다. 새 테이블·API 없음.
- 한 번에 366일(윤년 1년)까지. 기간 안 어느 날이든 집계 행이 없으면 409(먼저 #29 재계산).
- 휴가는 판정할 때 `ApprovedLeaveProvider`에서 읽는다. `Leave`에 `paid`(유급 여부)를 더했다 — 근로시간 계산에는 쓰지 않는다. 실제 휴가 데이터는 #34.

## 3. 판정 순서
1. 근무유형 미배정일(`pattern_id` 없음) → `NOT_SCHEDULED`(소정근로일을 알 수 없어 세지 않음). #29 집계는 이날을 소정근로일로 계산하고 `NO_WORK_PATTERN`을 남긴다.
2. 휴일(주휴일·공휴일·대체공휴일·회사휴일) → `HOLIDAY`, 휴무일 → `OFF_DAY`. 그날 일했어도 소정근로일이 아니다.
3. 소정근로일에 승인된 종일 휴가 → `PAID_LEAVE`/`UNPAID_LEAVE`.
4. 소정근로일에 출근 기록(첫 출근)이 있음 → `PRESENT`. 지각·조퇴·퇴근 누락(`MISSING_OUT`)도 출근.
5. 소정근로일에 반차만 있고 출근 기록 없음 → 휴가(유급·무급). **미확정**: 나머지 반일 미출근을 결근으로 볼지 저장소 주인 판단 대기.
6. 그 밖의 소정근로일 → `ABSENT`.

소정근로일 수 = `PRESENT`+`ABSENT`+`PAID_LEAVE`+`UNPAID_LEAVE`. 출근간주(제60조 제6항)나 소정근로일에서 빼는 기간(정당한 쟁의행위 등)을 반영한 출근율은 #33에서 계산한다.

## 4. 법령 확인
근로기준법 제60조 원문(law.go.kr)은 이 실행 환경에서 자동 조회하지 못해 미확인. 이 판정에는 법정 수치가 없어 legal_rate를 쓰지 않는다.
