# 연차 산정 기준 설계안 (#21)

결정: **입사일 기준과 회계연도 기준을 둘 다 지원하고, 회사 설정으로 선택한다**
(2026-11-11 사람 답변, 텔레그램)

관련 법령: 근로기준법 제60조(연차 유급휴가).
일수·출근율·가산 주기 등 수치는 코드에 쓰지 않고 `legal_rate`의 `ANNUAL_LEAVE_*` 항목(V003)에서 읽는다.
회계연도 기준 운영(입사 첫해 비례 부여, 퇴직 시 정산)은 조문에 직접 규정된 방식이 아니라 고용노동부 행정해석에 따른 실무이므로,
**구현 이슈에서 해당 행정해석 원문(moel.go.kr)을 확인한 뒤 계산식을 확정한다**(§6). 이 문서는 구조만 정한다.

## 1. 두 방식
| 방식 | 코드 | 발생 시점 | 계산 근거 |
|---|---|---|---|
| 입사일 기준 | `HIRE_DATE` | 사원별 입사일 기념일마다 | 근로기준법 제60조 원칙 (제1항·제2항·제4항) |
| 회계연도 기준 | `FISCAL_YEAR` | 회사가 정한 회계연도 시작일(기본 1/1)에 일괄 | 행정해석에 따른 실무. 근로자에게 불리하지 않아야 함 |

- 입사일 기준이 법의 원칙이고, 회계연도 기준은 관리 편의를 위한 대체 방식이다.
- 회계연도 기준을 쓰더라도 **퇴직 시점에 입사일 기준으로 다시 계산해 비교**하고, 입사일 기준 일수가 더 많으면 차이를 정산 대상으로 넘긴다(§4).

## 2. 회사 설정
회사(사업장) 단위 설정 테이블에 유효기간 방식(#8과 같은 `[valid_from, valid_to)`)으로 둔다. 방식 변경 이력을 남겨 과거 연도를 재계산할 수 있게 한다.

| 컬럼 | 설명 |
|---|---|
| `company_id` | 회사(또는 사업장) |
| `leave_basis` | `HIRE_DATE` / `FISCAL_YEAR` |
| `fiscal_year_start_mmdd` | 회계연도 시작 월일(기본 `0101`). `FISCAL_YEAR`일 때만 사용 |
| `valid_from`, `valid_to` | 설정 적용 기간 (종료 NULL = 현재) |
| `created_at`, `created_by` | 감사 정보 |

- 테이블·마이그레이션은 사원·회사 테이블이 생기는 근태 구현 이슈에서 만든다(이번 이슈는 결정 기록만, 마이그레이션 번호 사용 안 함).
- 방식 전환(예: 입사일 → 회계연도) 시 전환 연도의 처리 규칙은 §6 미결.

## 3. 계산 구조
```
AnnualLeaveCalculator (interface)
 ├─ HireDateBasisCalculator     // 근로기준법 제60조 제1항·제2항·제4항
 └─ FiscalYearBasisCalculator   // 행정해석 기반, 원문 확인 후 구현
AnnualLeaveSettlement           // 퇴직 시 두 방식 비교 → 차이 일수
```
- 입력: 입사일, 기준일, 출근율 판단 자료(근태 집계), 회사 설정, `legal_rate` 값(기준일 시점).
- 출력: 발생 내역 행(발생일, 일수, 발생 사유 코드, 근거 조문, 산정 방식). 발생 내역은 수정이 아니라 추가로 관리한다.
- 날짜는 `Asia/Seoul`, 일수는 정수 일 단위가 기본. 회계연도 기준 첫해 비례 부여에서 소수 일수가 생길 경우의 처리(올림·시간 단위 환산 등)는 §6 미결.
- 두 계산기는 같은 근태 집계 입력을 쓰므로 출근율 판단 로직은 공통 모듈로 분리한다.

## 4. 퇴직 정산
- `FISCAL_YEAR` 회사의 퇴직자는 퇴직일 기준으로 입사일 기준 총 발생 일수와 회계연도 기준 총 발생 일수를 비교한다.
- 입사일 기준이 더 많으면 차이 일수를 미사용 연차 정산(수당) 대상에 더한다. 수당 금액 계산은 급여 모듈 이슈에서 한다.
- 회계연도 기준이 더 많은 경우 회수(차감)할지는 정책·법령 확인이 필요하다(§6).

## 5. 테스트 항목 (구현 이슈에서)
정답값은 사람이 검수한 `tests/legal-fixtures/` 파일만 쓴다.
- 입사일 기준: 1년 미만 월별 발생, 1년 경과 시 발생, 가산 주기 경계, 상한 도달, 출근율 미달
- 회계연도 기준: 회계연도 시작일 직전·직후 입사, 입사 둘째 해 비례 부여, 회계연도 시작일이 1/1이 아닌 회사
- 퇴직 정산: 입사일 기준이 많은 경우 / 같은 경우 / 회계연도 기준이 많은 경우
- 회사 설정 유효기간: 방식 변경 전후 연도 재계산
- 윤년(2/29 입사) 기념일 처리

## 6. 아직 정하지 않은 것 (구현 이슈에서 질문)
- 회계연도 기준 입사 첫해·둘째 해 비례 부여 계산식 — 고용노동부 행정해석 원문 확인 필요
- 비례 계산 시 소수 일수 처리(올림/반올림/시간 단위 부여)
- 회계연도 기준이 입사일 기준보다 많이 부여된 퇴직자의 차감 여부
- 방식 전환(입사일 ↔ 회계연도) 시 전환 연도 처리 규칙
- 2/29 입사자의 평년 기념일(2/28 또는 3/1)
- 설정 단위를 회사로 할지 사업장으로 할지(#9 사업장코드와 연계)

## 7. 구현 현황 (#33, 2026-11-18)
- `attendance/AnnualLeaveRules`: 입사일 기준 순수 함수 `accruals(입사일, 기준일, 마지막 근무일, 출근 자료, 발생일 기준 legal_rate)`. 발생 내역(발생일·종류·일수·판단 기간·마지막 사용 가능일)을 돌려준다.
  - 최초 1년: 1개월 개근마다 발생(제2항). 최초 1년이 끝날 때까지 사용(제7항 단서).
  - 1년마다: 출근율이 기준 이상이면 기본 일수에 가산을 더하고 상한을 적용한다(제1항·제4항). 기준 미달이면 그 1년 중 개근한 달 수만큼 발생(제2항). 발생일부터 1년간 사용(제7항).
  - 기간은 민법 제157조 단서·제160조 제2항·제3항으로 센다(`DismissalNoticeChecker.lastDayOfMonths` 재사용). 2/29 입사자의 1년은 다음 해 2/28에 끝나고 3/1에 발생한다(§6 2/29 질문의 잠정 처리, fixture로 확인).
  - 기간이 끝난 다음 날(발생일)에 재직 중이어야 발생한다(마지막 근무일 ≥ 발생일).
  - 출근으로 보는 기간(제6항)은 호출하는 쪽이 넘긴다. #59 휴직 기간 조회(`LeavePeriodView`)에는 휴직 유형이 없어서 육아휴직 등을 아직 구분하지 못한다.
- `attendance/AnnualLeaveLegalRates`: `ANNUAL_LEAVE_*` 7개 항목을 발생일 기준으로 읽는다. 값이 없으면 예외.
- 단위 테스트는 법정 값과 다른 시험용 기준값으로 계산 구조만 검사한다. 법정 정답은 `tests/legal-fixtures/annual-leave*.csv`로 판정한다.

## 8. 구현 현황 2 (#33, 2026-11-20)
- 입사일 기준: 법률 제17185호 부칙 제2조 반영 — 2020-03-31 전에 발생한 최초 1년 월 단위분은 발생일부터 1년, 그 뒤 발생분은 최초 1년 끝까지 사용(제60조 제7항 단서). 시행일은 법률 시행일이라 상수(`LAW_17185_EFFECTIVE`)로 둔다.
- 최초 1년 출근율 미달이면 그 1년 중 개근 월수만큼 1년이 끝난 다음 날 한 건(`MONTHLY_LOW_ATTENDANCE`)으로 발생하고, 최초 1년 월 단위분과 따로 준다(fixture README, 법제처 24-0114·24-0674). 제4항 가산 연수는 출근율 미달 연도도 계속근로연수에 넣는다(1350 상담 1000135863).
- `AnnualLeaveFixtureTest`: `annual-leave.csv` 20건 모두 일치(시드 `legal_rate_hr_current.sql` 값, 실제 `AnnualLeaveLegalRates` 조회 경로).
- 회계연도 기준 `attendance/AnnualLeaveFiscalYear`(§6 미결 중 아래를 행정해석으로 확정):
  - 최초 1년 월 단위분은 입사일 기준과 같다.
  - 입사 회계연도 남은 기간분은 다음 회계연도 시작일에 `기본 일수 × 출근한 소정근로일수 ÷ 그 회계연도 소정근로일수`(근기68207-620). 소수는 반올림하지 않고 정확한 분수(`LeaveDays`)로 둔다.
  - 온전한 회계연도는 출근율 기준 이상이면 제1항·제4항 일수, 미달이면 그 회계연도 개근 월수(회계연도 시작일 기준 달)만큼 다음 회계연도 시작일에 한 건.
  - 퇴직 정산 `settlement`: 차이 = 입사일 기준 − 회계연도 기준. 양수만 추가 정산, 음수는 차감하지 않는다(근로기준과-5802, 1350 상담 1000306110).
  - **미확정**: 제4항 가산 연수에 입사 회계연도 일부를 1년으로 세는지 원문이 없다(seed-sources §#33 회계연도). 두 해석의 일수가 다른 발생분은 `UnresolvedIncrementException`으로 멈춘다(법정 값으로 입사 3번째 회계연도 발생분부터 해당).
  - `AnnualLeaveFiscalYearFixtureTest`: `annual-leave-fiscal-year.csv` 7건 모두 일치. 월 단위분은 전체 내역이라 재직자 행은 기준일과 최초 1년 마지막 날 중 늦은 날까지 계산한다.
- 남은 것(선행 필요): 회사별 산정 방식 설정 테이블(§2), 연차 원장(발생/사용/소멸)과 매일 발생 배치. 배치에는 일별 결근 판정(현재 `attendance_daily_summary`에 결근 열 없음), 제60조 제6항 사유별 기간(업무상 재해 휴업·출산전후휴가·육아휴직 — 발령 `LEAVE`에 유형 없음, 출산전후휴가·산재 휴업 기록 없음), 연차 사용(휴가 신청) 기록이 먼저 있어야 한다.
