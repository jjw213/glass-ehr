# 연차 산정 기준 설계안 (#21)

결정: **입사일 기준과 회계연도 기준을 둘 다 지원하고, 회사 설정으로 선택한다**
(2026-11-11 사람 답변, 텔레그램)

관련 법령: 근로기준법 제60조(연차 유급휴가).
일수·출근율·가산 주기 등 수치는 코드에 쓰지 않고 `legal_rate`의 `ANNUAL_LEAVE_*` 항목(V003)에서 읽는다.
회계연도 기준 운영(입사 첫해 비례 부여, 퇴직 시 정산)은 조문에 직접 규정된 방식이 아니라 고용노동부 행정해석에 따른 실무이므로,
**구현 이슈에서 해당 행정해석 원문(moel.go.kr)을 확인한 뒤 계산식을 확정한다**(§6). 이 문서는 구조만 정한다.

## 1. 두 방식
| 방식 | 코드 | 발생 시점 | 계산 근거 |
|---|---|---|---|
| 입사일 기준 | `HIRE_DATE` | 사원별 입사일 기념일마다 | 근로기준법 제60조 원칙 (제1항·제2항·제4항) |
| 회계연도 기준 | `FISCAL_YEAR` | 회사가 정한 회계연도 시작일(기본 1/1)에 일괄 | 행정해석에 따른 실무. 근로자에게 불리하지 않아야 함 |

- 입사일 기준이 법의 원칙이고, 회계연도 기준은 관리 편의를 위한 대체 방식이다.
- 회계연도 기준을 쓰더라도 **퇴직 시점에 입사일 기준으로 다시 계산해 비교**하고, 입사일 기준 일수가 더 많으면 차이를 정산 대상으로 넘긴다(§4).

## 2. 회사 설정
회사(사업장) 단위 설정 테이블에 유효기간 방식(#8과 같은 `[valid_from, valid_to)`)으로 둔다. 방식 변경 이력을 남겨 과거 연도를 재계산할 수 있게 한다.

| 컬럼 | 설명 |
|---|---|
| `company_id` | 회사(또는 사업장) |
| `leave_basis` | `HIRE_DATE` / `FISCAL_YEAR` |
| `fiscal_year_start_mmdd` | 회계연도 시작 월일(기본 `0101`). `FISCAL_YEAR`일 때만 사용 |
| `valid_from`, `valid_to` | 설정 적용 기간 (종료 NULL = 현재) |
| `created_at`, `created_by` | 감사 정보 |

- 테이블·마이그레이션은 사원·회사 테이블이 생기는 근태 구현 이슈에서 만든다(이번 이슈는 결정 기록만, 마이그레이션 번호 사용 안 함).
- 방식 전환(예: 입사일 → 회계연도) 시 전환 연도의 처리 규칙은 §6 미결.

## 3. 계산 구조
```
AnnualLeaveCalculator (interface)
 ├─ HireDateBasisCalculator     // 근로기준법 제60조 제1항·제2항·제4항
 └─ FiscalYearBasisCalculator   // 행정해석 기반, 원문 확인 후 구현
AnnualLeaveSettlement           // 퇴직 시 두 방식 비교 → 차이 일수
```
- 입력: 입사일, 기준일, 출근율 판단 자료(근태 집계), 회사 설정, `legal_rate` 값(기준일 시점).
- 출력: 발생 내역 행(발생일, 일수, 발생 사유 코드, 근거 조문, 산정 방식). 발생 내역은 수정이 아니라 추가로 관리한다.
- 날짜는 `Asia/Seoul`, 일수는 정수 일 단위가 기본. 회계연도 기준 첫해 비례 부여에서 소수 일수가 생길 경우의 처리(올림·시간 단위 환산 등)는 §6 미결.
- 두 계산기는 같은 근태 집계 입력을 쓰므로 출근율 판단 로직은 공통 모듈로 분리한다.

## 4. 퇴직 정산
- `FISCAL_YEAR` 회사의 퇴직자는 퇴직일 기준으로 입사일 기준 총 발생 일수와 회계연도 기준 총 발생 일수를 비교한다.
- 입사일 기준이 더 많으면 차이 일수를 미사용 연차 정산(수당) 대상에 더한다. 수당 금액 계산은 급여 모듈 이슈에서 한다.
- 회계연도 기준이 더 많은 경우 회수(차감)할지는 정책·법령 확인이 필요하다(§6).

## 5. 테스트 항목 (구현 이슈에서)
정답값은 사람이 검수한 `tests/legal-fixtures/` 파일만 쓴다.
- 입사일 기준: 1년 미만 월별 발생, 1년 경과 시 발생, 가산 주기 경계, 상한 도달, 출근율 미달
- 회계연도 기준: 회계연도 시작일 직전·직후 입사, 입사 둘째 해 비례 부여, 회계연도 시작일이 1/1이 아닌 회사
- 퇴직 정산: 입사일 기준이 많은 경우 / 같은 경우 / 회계연도 기준이 많은 경우
- 회사 설정 유효기간: 방식 변경 전후 연도 재계산
- 윤년(2/29 입사) 기념일 처리

## 6. 아직 정하지 않은 것 (구현 이슈에서 질문)
- 회계연도 기준 입사 첫해·둘째 해 비례 부여 계산식 — 고용노동부 행정해석 원문 확인 필요
- 비례 계산 시 소수 일수 처리(올림/반올림/시간 단위 부여)
- 회계연도 기준이 입사일 기준보다 많이 부여된 퇴직자의 차감 여부
- 방식 전환(입사일 ↔ 회계연도) 시 전환 연도 처리 규칙
- 2/29 입사자의 평년 기념일(2/28 또는 3/1)
- 설정 단위를 회사로 할지 사업장으로 할지(#9 사업장코드와 연계)
