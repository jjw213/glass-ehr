# 근무제 범위 설계안 (#23)

결정: **1차에서 표준 근로시간제 + 탄력적 근로시간제 + 선택적 근로시간제 + 재량근로시간제를 한 번에 지원한다**
(2026-11-11 사람 답변, 텔레그램)

관련 법령: 근로기준법 제50조(근로시간), 제51조(3개월 이내의 탄력적 근로시간제), 제51조의2(3개월을 초과하는 탄력적 근로시간제),
제52조(선택적 근로시간제), 제58조(근로시간 계산의 특례).
단위기간·정산기간 한도, 1주·1일 상한 시간 등 **수치는 코드에 쓰지 않고 `legal_rate` 항목으로 등록해 읽는다.**
이 문서는 구조만 정한다. 조문 세부(요건·한도·서면합의 필수 기재 사항)는 구현 이슈에서 law.go.kr 현행 원문을 확인한 뒤 확정한다(§7).

## 1. 지원 근무제
| 코드 | 근무제 | 근거 | 도입 요건(구조) |
|---|---|---|---|
| `STANDARD` | 표준 근로시간제 | 근로기준법 제50조 | 없음(기본값) |
| `FLEXIBLE_SHORT` | 탄력적 근로시간제(단위기간 짧은 유형) | 근로기준법 제51조 제1항 | 취업규칙(또는 이에 준하는 것) 근거 |
| `FLEXIBLE_WRITTEN` | 탄력적 근로시간제(서면합의 유형) | 근로기준법 제51조 제2항 | 근로자대표와의 서면합의 |
| `FLEXIBLE_LONG` | 3개월 초과 탄력적 근로시간제 | 근로기준법 제51조의2 | 근로자대표와의 서면합의 |
| `SELECTIVE` | 선택적 근로시간제 | 근로기준법 제52조 | 취업규칙 근거 + 근로자대표와의 서면합의 |
| `DISCRETIONARY` | 재량근로시간제 | 근로기준법 제58조 제3항 | 근로자대표와의 서면합의, 대상 업무 한정(시행령) |

- 탄력적 근로시간제는 조문별로 도입 요건(취업규칙 / 서면합의)과 단위기간 한도가 다르므로 코드를 나눈다.
  각 유형의 단위기간 한도와 1주·1일 상한은 원문 확인 후 `legal_rate` 항목으로 등록한다(§5).
- 제58조 제1항·제2항(사업장 밖 간주근로시간제)은 이번 결정 범위가 아니다. 필요하면 별도 이슈로 추가한다.
- 30인 이상 사업장 기준이므로 상시근로자 수에 따른 적용 제외 분기는 두지 않는다.

## 2. 근무제 정의(회사 단위)
회사(사업장)마다 사용할 근무제를 "근무제 정의"로 등록한다. 같은 유형이라도 단위기간·코어타임 등이 다르면 정의를 여러 개 둔다.

| 컬럼 | 설명 |
|---|---|
| `schedule_type_id` | 근무제 정의 ID |
| `company_id` | 회사(또는 사업장) |
| `schedule_kind` | §1의 코드 |
| `name` | 표시 이름 |
| `unit_period_days` / `unit_period_months` | 탄력적 단위기간 또는 선택적 정산기간 (유형별 한도는 `legal_rate`로 검사) |
| `core_time_start`, `core_time_end` | 선택적: 의무 근로시간대(선택) |
| `flex_time_start`, `flex_time_end` | 선택적: 선택 근로시간대(선택) |
| `deemed_minutes_per_day` | 재량: 서면합의로 정한 1일 근로 간주 시간(분) |
| `agreement_id` | 서면합의 문서 참조 (`STANDARD`·`FLEXIBLE_SHORT`는 NULL 허용) |
| `valid_from`, `valid_to` | 유효기간 `[valid_from, valid_to)`, 종료 NULL = 현재 (#8과 같은 방식) |

- 시간은 분 단위 정수, 날짜는 `Asia/Seoul` (AGENTS.md 코드 규칙).

## 3. 서면합의 관리
탄력적(제51조 제2항, 제51조의2)·선택적·재량근로는 서면합의가 없으면 쓸 수 없으므로, 합의 문서를 별도로 관리하고 근무제 정의와 연결한다.

| 컬럼 | 설명 |
|---|---|
| `agreement_id` | 합의 ID |
| `company_id` | 회사(또는 사업장) |
| `agreement_kind` | 어느 근무제에 대한 합의인지 |
| `signed_date` | 체결일 |
| `effective_from`, `effective_to` | 합의 유효기간 |
| `worker_representative` | 근로자대표 구분(과반수 노조 / 과반수 대표자) — 실명 등 개인정보는 저장 방식 별도 결정 |
| `document_ref` | 합의서 파일 참조 |
| 조문별 필수 기재 사항 | 대상 근로자 범위, 단위기간(정산기간), 근로일·근로시간 등 — 항목은 원문 확인 후 확정(§7) |

검증 규칙(구조):
- 서면합의가 필요한 근무제 정의는 유효한 합의 없이 저장·배정할 수 없다.
- 근무제 정의의 유효기간은 연결된 합의의 유효기간 안에 있어야 한다. 합의가 만료되면 배정을 새로 만들 수 없고, 화면에 경고를 띄운다.
- 합의서 기재 사항과 근무제 정의 값(단위기간 등)이 다르면 저장을 막는다.

## 4. 사원 배정
사원별 근무제 배정을 유효기간 방식으로 둔다(발령 이력처럼 수정이 아니라 추가).

| 컬럼 | 설명 |
|---|---|
| `emp_id` | 사원(불변 ID, #9) |
| `schedule_type_id` | 근무제 정의 |
| `valid_from`, `valid_to` | 배정 기간 |

- 하나의 날짜에 사원 한 명은 근무제 하나만 갖는다(겹침 금지, `legal_rate`와 같은 쓰기 계약).
- 탄력적·선택적 근무제의 단위기간(정산기간) 도중 근무제가 바뀌거나 입사·퇴직하는 경우의 정산 규칙은 §7 미결.

## 5. 계산 구조
```
WorkScheduleCalculator (interface)        // 기준 근로시간·연장근로 판정
 ├─ StandardCalculator        // 근로기준법 제50조, 제53조 제1항
 ├─ FlexibleCalculator        // 근로기준법 제51조, 제51조의2 (단위기간 평균)
 ├─ SelectiveCalculator       // 근로기준법 제52조 (정산기간 총량)
 └─ DiscretionaryCalculator   // 근로기준법 제58조 제3항 (서면합의 간주시간)
```
- 입력: 사원 배정, 근무제 정의, 출퇴근 기록(분 단위), 기준일 시점의 `legal_rate` 값.
- 출력: 일·주·단위기간별 소정근로/연장/야간/휴일 분. 가산 임금 계산은 급여 모듈에서 `OVERTIME_PREMIUM_RATE` 등을 읽어 한다.
- 야간·휴일근로 가산(제56조)은 근무제와 관계없이 적용되는지 여부를 원문·행정해석으로 확인해 공통 모듈로 둔다(§7).
- 등록이 필요한 `legal_rate` 후보 항목(값은 사람이 원문 확인 후 입력, 항목 등록은 구현 이슈의 마이그레이션에서):
  - 1주·1일 기준 근로시간 (제50조 제1항·제2항)
  - 탄력적 유형별 단위기간 한도, 특정 주·특정 일 상한 (제51조, 제51조의2)
  - 선택적 정산기간 한도(일반 / 예외 업무) (제52조)
  - 3개월 초과 탄력적의 근로일 간 휴식시간 (제51조의2)

## 6. 테스트 항목 (구현 이슈에서)
정답값은 사람이 검수한 `tests/legal-fixtures/` 파일만 쓴다.
- 표준: 1일·1주 기준 초과분 연장근로 판정, 주 경계(요일 기준)
- 탄력적: 단위기간 평균 이내/초과, 특정 주·특정 일 상한 초과, 단위기간 한도 초과 정의 저장 거부
- 선택적: 정산기간 총량 이내/초과, 코어타임 미준수 표시, 정산기간 한도 초과 정의 저장 거부
- 재량: 실제 시간과 관계없이 간주시간 적용, 대상 업무가 아닌 정의 저장 거부
- 서면합의: 합의 없음·만료·기재 사항 불일치 시 저장/배정 거부
- 배정: 겹침 거부, 단위기간 도중 근무제 변경·입사·퇴직

## 7. 아직 정하지 않은 것 (구현 이슈에서 질문)
- 각 조문의 단위기간·정산기간 한도와 1주·1일 상한 수치 — law.go.kr 현행 원문 확인 후 `legal_rate` 값으로 입력
- 조문별 서면합의 필수 기재 사항 목록
- 재량근로 대상 업무 목록(근로기준법 시행령) — 코드값으로 둘지 회사가 고르게 할지
- 단위기간(정산기간) 도중 입사·퇴직·근무제 변경 시 임금 정산 방식(제51조의3 등 관련 조문 확인 필요)
- 3개월 초과 탄력적의 임금 보전 방안 신고 처리 여부
- 재량근로자에게 야간·휴일 가산을 어떻게 집계할지(행정해석 확인)
- 근로자대표 정보 저장 범위(개인정보 최소 수집)
- 설정 단위를 회사로 할지 사업장으로 할지(#9 사업장코드, #21과 함께 결정)
