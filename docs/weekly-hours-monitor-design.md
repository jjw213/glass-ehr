# 주 52시간 모니터링 (#31)

## 1. 근거와 기준값
| 조문 | 내용 | 값 출처 |
|---|---|---|
| 근로기준법 제2조 제1항 제7호 | 1주 = 휴일을 포함한 7일 → 휴일근로도 주간 누적에 넣는다 | — |
| 근로기준법 제50조 제1항 | 1주 근로시간(휴게 제외) | legal_rate `WEEKLY_STANDARD_WORK_HOURS` |
| 근로기준법 제53조 제1항 | 1주 연장근로 한도 | legal_rate `WEEKLY_OVERTIME_LIMIT_HOURS` |
| (회사 설정) | 한도까지 남은 분이 이 값 이하이면 '한도 근접' | `glassehr.attendance.weekly-hours-warn-remain-minutes` (기본 240) |

기준값은 그 주 월요일 기준으로 읽는다(주 중 개정 시 그 주는 월요일 값). 값이 없으면 409.
2026-11-19에 [근로기준법 제50조·제53조 원문](https://www.law.go.kr/%EB%B2%95%EB%A0%B9/%EA%B7%BC%EB%A1%9C%EA%B8%B0%EC%A4%80%EB%B2%95)과
[대법원 2023. 12. 7. 선고 2020도15393 판결](https://law.go.kr/LSW/precInfoP.do?mode=0&precSeq=238199),
[고용노동부 2024. 1. 22. 행정해석 변경 보도자료](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=16103)를 확인했다.
제53조 제1항의 주 12시간 한도 위반 여부는 일별 연장근로 합이 아니라 1주 총 실근로 중 40시간을 초과한 시간으로 판단하며,
소정근로일과 휴일근로를 구분하지 않는다. 제56조의 연장근로수당 산정 기준은 이 한도 판정과 별개다.

## 2. 계산
- 이번 주(서울 기준 오늘이 속한 월~일)를 `WorkHoursService.computeWeek`로 **저장하지 않고** 계산한다.
  재계산(`recalculate`)과 같은 규칙(#29)이라 아직 재계산하지 않은 오늘까지의 기록도 반영된다.
- 판정(`WeeklyHoursMonitor`, 순수 함수):
  1. 누적 실근로(소정 + 법내 초과 + 연장 + 휴일) ≤ 제50조 + 제53조 시간
  2. 한도 대상 연장(max(0, 1주 총 실근로 - 제50조 주간 기준)) ≤ 제53조 시간
  - 하나라도 넘으면 `OVER`, 남은 시간(둘 중 작은 값)이 경고 기준 이하이면 `NEAR`, 아니면 `NORMAL`. 한도와 같으면 `NEAR`.
- 퇴근 기록이 없는 날이 있으면 `missingOut`으로 표시한다(근로시간이 적게 잡혔을 수 있음).
- 정답 사례 fixture는 없다. 테스트는 임의 한도 값으로 경계(같음·1분 초과)와 일별 연장 합을 제53조 한도에 사용하지 않는 규칙을 본다.

## 3. API·권한
- `GET /api/attendance/weekly-hours/me` — 로그인 사원 본인. 사원과 연결되지 않은 계정은 403.
- `GET /api/attendance/weekly-hours/team` — `EMP_READ_ALL`(인사: 전체) 또는 `EMP_READ_DEPT`(부서장: 맡은 부서·하위부서).
  그 주에 재직한 사원만, 부서 안은 초과·근접 먼저 → 사번 순.

## 4. 화면
- 홈 대시보드 `이번 주 근로시간` 위젯: 게이지(초록·노랑·빨강), 누적·한도·연장, 근접·초과 시 본인 경고 문구.
- `/team`이 403이 아니면 부서별 표를 같은 위젯 아래에 붙인다. 근접·초과 행 강조. 모바일(≤899px)은 사원당 카드.

## 5. 범위 밖(후속 제안)
- 경고 알림 발송(메일·푸시)·부서장 알림함: 알림 모듈이 없어 화면 경고만 한다.
- 탄력적·선택적 근로시간제 단위기간 평균 한도(제51조·제52조) 판정: 이번 주 1주 한도만 본다.
- 지난 주·임의 주 조회.
