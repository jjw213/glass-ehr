# 인사발령 설계 (#16 → #58 발령 테이블·등록·확정)

#16(인사발령)을 셋으로 나눈 것 중 1번이다. 발령을 등록하고 확정하는 데까지만 하고, **사원 정보(employee)에 반영하는 일은 다음 이슈**에서 한다.

## 1. 근거 조문
2026-11-13 기준. law.go.kr 자동 조회가 되지 않아 원문을 다시 확인하지 못했다. 사람이 원문으로 확인해야 한다.

| 조문 | 구현 |
|---|---|
| 근로기준법 제23조 제1항 (정당한 이유 없이 해고, 휴직, 정직, 전직, 감봉, 그 밖의 징벌 금지) | 모든 발령에 사유 필수 (요청 `@NotBlank` + 서비스 검사 + DB `NOT NULL`·`LENGTH(TRIM(reason)) > 0`) |
| 남녀고용평등과 일·가정 양립 지원에 관한 법률 제19조 (육아휴직) | 휴직(`LEAVE`) 발령으로 등록, 휴직 시작·종료 예정일 필수 |

법정 수치(휴직 기간 상한 등)는 이번 범위에서 쓰지 않는다. 필요해지면 `legal_rate`에서 읽는다.

## 2. 테이블 (V014__hr_appointment.sql)
- `hr_appointment`: 발령번호(`appt_no`, 유일), 유형, 대상 사원, 발령일, 이전/이후 값(소속·직급·직책·재직상태), 사유, 휴직 시작·종료 예정일, 확정 여부(`confirmed_yn`)·확정일시.
- 발령번호: `AP-등록연도-6자리 순번`. 순번은 시퀀스 `hr_appointment_no_seq`에서 받아 연도와 상관없이 늘어난다. 롤백하면 빈 번호가 생길 수 있다.
- 재직상태: `ACTIVE`(재직)·`ON_LEAVE`(휴직)·`RETIRED`(퇴직). 사원 테이블에는 아직 재직상태 컬럼이 없다.
- 발령 유형 공통코드 `APPOINTMENT_TYPE`: HIRE(입사)·TRANSFER(전보)·PROMOTION(승진)·TITLE_CHANGE(직책)·LEAVE(휴직)·RETURN(복직)·RETIREMENT(퇴직). 로직이 코드값을 참조하므로 화면에서는 이름·정렬·사용 여부만 바꾼다.

## 3. 유형별 규칙 (AppointmentService)
| 유형 | 바꾸는 항목 | 재직상태 | 그 밖 |
|---|---|---|---|
| HIRE | 소속·직급(필수)·직책(선택) | → 재직 | 발령일 = 입사일. 사원마다 한 건. 이전 값 없음 |
| TRANSFER | 소속(필수, 지금과 달라야 함) | 그대로 | 부서는 발령일에 존속하고 폐지(예정)가 아니어야 함 |
| PROMOTION | 직급(필수, 지금과 달라야 함) | 그대로 | |
| TITLE_CHANGE | 직책(비우면 해제, 지금과 달라야 함) | 그대로 | |
| LEAVE | — | 재직 → 휴직 | 휴직 시작일 ≥ 발령일, 종료 예정일 ≥ 시작일 |
| RETURN | — | 휴직 → 재직 | |
| RETIREMENT | — | → 퇴직 | |

- 유형이 바꾸지 않는 항목은 이전 값을 그대로 옮긴다. 그 항목에 다른 값을 보내면 400.
- 이전 값: 소속·직급·직책은 사원 행의 현재 값, 재직상태는 발령일까지 **확정된** 다른 발령 중 마지막 것(발령일 → 확정일시 → ID 순)의 이후 재직상태. 그런 발령이 없으면 사원 퇴직일 기준(퇴직일 당일까지는 재직).
- 이전 값은 등록·수정·**확정** 때마다 다시 채우고 규칙을 다시 검사한다.
- 확정된 발령은 수정·삭제·재확정 불가(409). 미확정 발령은 수정·삭제 가능.
- 쓰기는 사원 행을 먼저 잠그고(`SELECT ... FOR UPDATE`) 발령 행을 잠가 다시 읽는다(근로계약과 같은 방식).

## 5. 다음 이슈로 넘기는 일
- 확정된 발령을 사원 정보(소속·직급·직책·퇴직)에 반영하고, 사원 재직상태(휴직 포함)를 저장하는 방식.
- 반영 전에는 확정됐지만 반영 안 된 앞선 발령이 이전 값(소속·직급·직책)에 들어가지 않는다. 반영 이슈에서 이전 값을 기준일 이력으로 채우도록 바꾼다.
- 휴직 사유 세분(육아휴직·질병휴직 등)과 법정 휴직 기간 검사(legal_rate).
- 쓰기 권한(인사담당) 검사(인증·권한 이슈), 목록 조회의 DB 단 필터·페이지.
