# 근로시간 집계 엔진 설계 (#29)

출퇴근 기록·근무유형(근무일정)·휴일 달력·승인된 휴가를 합쳐 사원별 **일별** 실근로시간을 계산하고
소정(기준시간 이내)·연장·야간·휴일(기준시간 이내)·휴일(기준시간 초과)로 나눈다. 급여 모듈은 이 집계 결과만 쓴다.
금액은 계산하지 않는다. 가산율은 근무일 기준 legal_rate 적용값을 집계 행에 함께 남긴다.

## 1. 근거 조문

| 조문 | 이 엔진에서 쓰는 내용 | legal_rate 항목 |
| --- | --- | --- |
| 근로기준법 제50조 제1항 | 1주 근로시간(휴게 제외) — 넘으면 연장 | `WEEKLY_STANDARD_WORK_HOURS` |
| 근로기준법 제50조 제2항 | 1일 근로시간(휴게 제외) — 넘으면 연장 | `DAILY_STANDARD_WORK_HOURS` |
| 근로기준법 제53조 제1항 | 연장근로 제한(한도 검사는 이 이슈 범위 밖, 집계값을 제공) | `WEEKLY_OVERTIME_LIMIT_HOURS` (미사용) |
| 근로기준법 제54조 제1항 | 휴게시간은 근로시간 도중에 주며 실근로에서 뺀다 | — |
| 근로기준법 제56조 제1항 | 연장근로 가산 | `OVERTIME_PREMIUM_RATE` |
| 근로기준법 제56조 제2항 | 휴일근로 가산, 기준시간 이내(제1호)·초과(제2호) | `HOLIDAY_PREMIUM_THRESHOLD_HOURS`, `HOLIDAY_PREMIUM_RATE`, `HOLIDAY_EXCESS_PREMIUM_RATE` |
| 근로기준법 제56조 제3항 | 야간근로(시작~다음 날 종료 시각) 가산 | `NIGHT_WORK_START_HOUR`, `NIGHT_WORK_END_HOUR`, `NIGHT_PREMIUM_RATE` |

수치는 코드에 없다. `WorkHoursLegalRules`가 근무일 기준으로 읽고, 값이 없으면 409(LegalRateException)로 멈추며 아무 행도 바꾸지 않는다.

## 2. 구조

- `WorkHoursCalculator` — 순수 함수. 입력 `DayInput`(근무일, 날 성격, 다음 날 성격, 소정근로시간, 근로 구간, 휴게 구간, 휴가, 기준값) → `DayResult`.
  `calculateWeek`가 월~일 한 주를 받아 1주 연장까지 반영한다.
- `WorkHoursLegalRules` — legal_rate → `Rules`(분)·`Rates`(퍼센트 숫자).
- `WorkHoursService` — 원자료를 모아 엔진을 돌리고 `attendance_daily_summary`(V022, MyBatis)에 쓴다.
- `ApprovedLeaveProvider` — 승인된 휴가 입력. 휴가 모듈이 없어서 지금은 `NoApprovedLeaveProvider`(휴가 없음). 휴가 모듈이 구현을 넣는다.
- API: `GET /api/attendance/daily-summaries?empId&from&to`(EMP_READ_ALL), `POST /api/attendance/daily-summaries/recalculate`(EMP_WRITE).

## 3. 계산 규칙

1. **근무 짝짓기**: 근무일 D의 시작은 D의 첫 출근, 끝은 시작 뒤 마지막 퇴근(다음 근무일 첫 출근 전, 시작부터 24시간 이내). 퇴근이 없으면 실근로 0분, `MISSING_OUT` 표시.
2. **실근로** = 근로 구간 합집합 − 휴게 구간 합집합. 휴게가 겹쳐도 한 번만, 근로와 겹친 만큼만 뺀다(반차로 근로 밖이 된 점심 휴게는 빼지 않는다).
   휴게는 근무유형의 휴게 한 구간이며, 휴게 시작이 시업보다 이르면 다음 날(야간조)이다.
3. **날 성격**: 휴일 달력(`HolidayService.isHoliday` 기준: 공휴일·대체공휴일·대체된 휴일·회사휴일, 대체된 원래 공휴일 제외)에 있으면 휴일.
   아니면 근무유형 요일 구분 W=소정근로일, O=휴무일, H=주휴일(휴일). 휴일인 날의 소정근로시간은 0.
4. **휴일근로**: 실근로 중 휴일인 역일(0시~24시)에 속한 분. 자정을 넘으면 0시 이후 분은 다음 날 성격을 따른다. 기준시간까지 '이내', 넘는 분은 '초과'.
5. **1일 연장**: 휴일이 아닌 실근로가 1일 기준시간을 넘는 분. 자정을 넘는 근무는 시작한 날의 하루로 본다.
6. **1주 연장**: 주(월~일)마다 연장이 아닌 평일 실근로를 날짜순으로 더해 1주 기준시간을 넘는 분을 그날 연장으로 옮긴다. 휴일근로와 휴가는 더하지 않는다.
7. **야간**: 실근로 중 야간 구간에 든 분. 연장·휴일과 겹쳐 따로 센다.
8. **휴가**: 실근로가 아니므로 연장 판단에 넣지 않고 `leave_minutes`로만 남긴다.

항상 `worked = regular + overtime + holiday + holiday_excess`(DB CHECK).

## 4. 저장·재계산

- 한 사원·근무일에 한 행(PK). 요청 기간을 월~일로 넓혀 계산한 뒤 그 기간 행을 지우고 다시 넣는다(한 트랜잭션). 같은 원자료면 결과가 같다.
- 원자료(출퇴근 기록·근무유형·휴일 달력)는 바꾸지 않는다. 근무유형은 배정 뒤 시각을 바꿀 수 없어서(#25) 과거 재계산이 안정적이다.
- 한 번에 93일까지(운영 보호용 값).

## 5. 정답 확인이 필요한 해석 (법령 정답 fixture로 확정)

아래는 구현한 해석이며, `tests/legal-fixtures/`의 근로시간 사례 정답이 들어오면 대조해 맞춘다.

1. 자정을 넘는 근무가 휴일로 이어질 때 0시 이후를 휴일근로로 보는지(역일 기준), 휴일 근무가 평일로 이어질 때 0시 이후를 평일 근로로 보는지.
2. 1주 기산 요일(지금 월요일)과 1주 연장 판단에 휴가·휴일근로를 넣지 않는 것.
3. 휴무일(O) 근로를 휴일근로가 아닌 평일 근로(1주 기준 초과 시 연장)로 보는 것.
4. 무급 회사휴일 근로를 휴일근로로 보는 것(휴일 달력 `isHoliday` 그대로).
5. 반차일 연장을 실근로 기준(휴가 시간 제외)으로 보는 것.
6. 단시간근로자의 소정근로시간 초과분(기간제법 제6조)은 이 이슈 범위 밖.
