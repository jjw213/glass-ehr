# Glass HR 기능 명세 (초안)

상시근로자 30인 이상 사업장 기준. 모듈별 상세 명세는 해당 모듈을 시작할 때 이 문서에 추가합니다.

## 0. 공통 기반
- 기준값 테이블 `legal_rate`: 항목코드, 적용시작일, 적용종료일, 값, 단위, 근거 조문, 출처 URL
  - 예: 최저임금(시간급), 국민연금·건강보험·장기요양·고용보험 요율, 비과세 한도
- 공통 결재: 신청 유형별 결재선을 관리자가 설정(유효기간 방식), 신청 시 결재선 스냅샷, 순차 결재. 상세는 `docs/approval-line-design.md`
- 공통코드, 감사 로그(누가 언제 무엇을 바꿨는지), 권한(관리자·인사담당·급여담당·일반 직원)

## 1. 인사·조직
- 조직: 회사, 부서(계층형), 직급, 직책, 직무
- 사원: 기본정보(고유식별정보 암호화·마스킹), 입사일, 고용형태(정규·계약·단시간), 소정근로시간
- 발령 이력: 입사, 부서이동, 승진, 휴직, 복직, 퇴직 (이력은 수정이 아니라 추가로 관리)

## 2. 근태 (예정)
- 근무일정, 출퇴근 기록, 연장·야간·휴일근로 집계, 연차 발생·사용, 휴가·휴직
- 관련: 근로기준법(근로시간, 휴게, 가산임금, 연차유급휴가), 남녀고용평등법(육아휴직 등)

## 3. 급여 (예정)
- 임금 항목(통상임금 포함 여부 구분), 근태 연동 수당, 4대보험, 소득세(간이세액표), 급여명세서, 퇴직금
- 관련: 근로기준법, 최저임금법, 소득세법, 근로자퇴직급여 보장법

### 메모: Node 서버에 있던 급여명세서 화면 요구사항 (#81)
Node `GET /api/payslips`(·`/api/bootstrap`의 `payslips`)와 급여 화면은 Spring으로 옮기지 않고, 급여 모듈 전까지 화면을 '준비 중'으로 바꿨다(데모 모드는 샘플 유지). 급여 모듈 기획 때 아래를 참고한다. 공제액 계산(요율 단순 적용)은 샘플일 뿐이라 따르지 않는다.
- 조회 범위: **본인 명세만**(다른 사원 명세는 안 보임). 지급월 최신순, 최근 5개월.
- 명세 한 건: 지급월 표시(`2026년 10월`), 지급월(`YYYY-MM`), 지급일(`YYYY-MM-DD`), 지급 항목 목록·공제 항목 목록(각 `항목명 + 금액(원 정수)`, 정해진 순서대로).
  - 예시 지급 항목: 기본급, 직책수당, 식대(비과세), 연장근로수당, 성과급(금액 0인 항목은 표시 안 함). 비과세 여부를 항목별로 구분.
  - 예시 공제 항목: 국민연금, 건강보험, 장기요양보험, 고용보험, 소득세, 지방소득세.
- 화면: 월 선택 칩, 실지급액(= 지급 총액 − 공제 총액)과 지급일, 지급·공제 비율 막대, 최근 5개월 실지급액 막대그래프(누르면 그 달 선택), 지급 내역·공제 내역 표(공제는 `-` 표시), 금액은 `1,234,000원` 형식.
- 금액 숨기기 버튼(`•••••••원`으로 가림), 인쇄 버튼, 명세가 없으면 "아직 발급된 급여명세서가 없어요".
- 급여 모듈에서 정할 것: 근로기준법 제48조 제2항 임금명세서 기재사항(계산방법 등, 조문·시행령 원문 확인 필요) 반영, 급여 조회 권한·조회 로그(docs/auth-design.md).

## 4. 평가 · 복리후생 · 교육 · 채용 (예정)
- 교육: 법정의무교육(직장 내 성희롱 예방, 장애인 인식개선, 개인정보보호 등) 이수 관리
- 채용: 채용절차의 공정화에 관한 법률 반영 (30인 이상 적용)
