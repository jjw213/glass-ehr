# Glass HR 기능 명세 (초안)

상시근로자 30인 이상 사업장 기준. 모듈별 상세 명세는 해당 모듈을 시작할 때 이 문서에 추가합니다.

## 0. 공통 기반
- 기준값 테이블 `legal_rate`: 항목코드, 적용시작일, 적용종료일, 값, 단위, 근거 조문, 출처 URL
  - 예: 최저임금(시간급), 국민연금·건강보험·장기요양·고용보험 요율, 비과세 한도
- 공통 결재: 신청 유형별 결재선을 관리자가 설정(유효기간 방식), 신청 시 결재선 스냅샷, 순차 결재. 상세는 `docs/approval-line-design.md`
- 공통코드, 감사 로그(누가 언제 무엇을 바꿨는지), 권한(관리자·인사담당·급여담당·일반 직원)

## 1. 인사·조직
- 조직: 회사, 부서(계층형), 직급, 직책, 직무
- 사원: 기본정보(고유식별정보 암호화·마스킹), 입사일, 고용형태(정규·계약·단시간), 소정근로시간
- 발령 이력: 입사, 부서이동, 승진, 휴직, 복직, 퇴직 (이력은 수정이 아니라 추가로 관리)

## 2. 근태 (예정)
- 근무일정, 출퇴근 기록, 연장·야간·휴일근로 집계, 연차 발생·사용, 휴가·휴직
- 관련: 근로기준법(근로시간, 휴게, 가산임금, 연차유급휴가), 남녀고용평등법(육아휴직 등)

## 3. 급여 (예정)
- 임금 항목(통상임금 포함 여부 구분), 근태 연동 수당, 4대보험, 소득세(간이세액표), 급여명세서, 퇴직금
- 관련: 근로기준법, 최저임금법, 소득세법, 근로자퇴직급여 보장법

## 4. 평가 · 복리후생 · 교육 · 채용 (예정)
- 교육: 법정의무교육(직장 내 성희롱 예방, 장애인 인식개선, 개인정보보호 등) 이수 관리
- 채용: 채용절차의 공정화에 관한 법률 반영 (30인 이상 적용)
