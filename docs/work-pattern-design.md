# 근무유형·근무일정 설계 (#25)

표준 근무제(#23 §1의 `STANDARD`)에서 쓰는 근무유형(시업·종업, 휴게, 소정근로시간, 주휴일)과 사원별 배정 이력이다.
탄력적·선택적·재량근로 정의와 서면합의(#23 §2·§3)는 별도 이슈에서 이 구조 위에 붙인다.

## 1. 테이블 (V016__work_pattern.sql)
`work_pattern`
| 컬럼 | 설명 |
|---|---|
| `pattern_code` / `pattern_name` | 코드(불변, 영문 대문자·숫자·밑줄), 이름 |
| `work_start_min`, `work_end_min` | 시업·종업 시각(자정부터의 분). 종업 ≤ 시업이면 다음 날 종업(야간조) |
| `break_start_min`, `break_minutes` | 휴게 한 구간. 휴게 없음 = NULL, 0 |
| `day_types` | 월~일 7글자. `W` 근무일, `O` 휴무일(무급), `H` 주휴일(제55조 제1항 유급휴일). DB가 `H` 1개 이상을 강제 |
| `daily_contract_minutes`, `weekly_contract_minutes` | 서비스가 계산해 저장: 1일 = (종업-시업) - 휴게(제50조 제3항), 1주 = 1일 × 근무일 수 |
| `use_yn`, `note` | 사용 여부(배정 가능 여부), 비고 |

`emp_work_pattern` — 사원별 배정 이력 `[valid_from, valid_to)`, 추가로만 쌓는다. `(emp_id, valid_from)` 유일.

## 2. 저장 검사 (WorkPatternRules, WorkPatternLegalLimits)
법정 수치는 코드·DDL에 쓰지 않고 `legal_rate`에서 적용일 기준으로 읽는다(V015 항목, 값은 `seed/legal_rate_work_pattern.sql` — Codex 법령 데이터 PR #64, 사람 승인. 2008-07-01부터 제공).

| 검사 | 근거 | legal_rate 항목 |
|---|---|---|
| 1일 소정근로시간 ≤ 한도 | 근로기준법 제50조 제2항 | `DAILY_STANDARD_WORK_HOURS` |
| 1주 소정근로시간 ≤ 한도 | 근로기준법 제50조 제1항 | `WEEKLY_STANDARD_WORK_HOURS` |
| 근로시간 ≥ 짧은 구간 기준이면 휴게 ≥ 짧은 구간 최소, 긴 구간 기준 이상이면 긴 구간 최소 | 근로기준법 제54조 제1항 | `BREAK_SHORT_THRESHOLD_HOURS`, `BREAK_SHORT_MIN_MINUTES`, `BREAK_LONG_THRESHOLD_HOURS`, `BREAK_LONG_MIN_MINUTES` |
| 휴게는 근로시간 도중(시업 직후·종업 직전 불가) | 근로기준법 제54조 제1항 | (형식 검사) |
| 주휴일 ≥ 최소 횟수 | 근로기준법 제55조 제1항 | `WEEKLY_PAID_HOLIDAY_MIN_COUNT` |

- 근무유형 저장 시점: 서울 기준 **오늘** 적용값으로 검사. 배정 시점: **배정 적용 시작일** 적용값으로 다시 검사.
- 위반이 있으면 422와 위반 목록(`violations[]`)을 돌려주고 저장하지 않는다. 기준값이 없으면 409(기본값으로 검사하지 않음).
- 휴게 기준 "4시간인 경우" 등의 경계는 "이상"으로 해석해 구현했다. `tests/legal-fixtures/work-pattern-limits.csv`(20건: 4시간·3시간59분·8시간·8시간1분, 1주 40시간 정확히·초과, 주휴일 0일, 시업 직후·종업 직전 휴게, 2021-06-30/07-01, 윤일)가 같은 해석이며 `WorkPatternLimitsFixtureTest`가 시드 값으로 모두 검증한다.
- 권한(#19): 목록·미리보기는 로그인 사용자 모두, 등록·수정·배정은 `EMP_WRITE`(관리자·인사), 배정 조회는 `EMP_READ_ALL`(관리자·인사·급여). 배정 요청자는 서버가 확인한 로그인 사용자로 기록한다.

## 3. 정책
- 배정에 쓰인 근무유형은 시각·휴게·요일을 바꿀 수 없다(과거 근태 재계산이 달라지지 않게). 이름·사용 여부·비고만 바꾼다.
- 배정은 마지막 배정 시작일 뒤에만 추가하고, 마지막 배정을 새 시작일로 닫는다. 입사일 전·퇴직일 뒤 배정은 거부(퇴직일 당일까지 재직).
- 근무유형·배정 CRUD는 JPA(마스터 데이터), legal_rate 조회는 기존 MyBatis `LegalRateService`.
- 주휴일은 모든 근무유형에 필수다(이슈 완료 기준). 제18조 제3항 단시간근로자 예외는 적용하지 않고 더 보호적인 쪽으로 둔다.
- 제18조(단시간근로자 비례): 근무유형이 1일·1주 소정근로시간을 저장해 두므로 연차·급여 이슈에서 통상근로자와 비교해 비례 계산한다. 비교 대상 통상근로자 결정은 그 이슈에서 정한다.
